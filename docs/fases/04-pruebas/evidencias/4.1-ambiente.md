# 4.1 Ambiente aislado y datos controlados

**Estado (2026-11-11):** hecho y ejecutado en local. Reutilizado por CI (jobs `pruebas`, `e2e`, `dast` y `resiliencia` de `.github/workflows/ci.yml`; **aún no ejecutados en GitHub**, ver [README](../README.md#estado)).

| Qué | Comando | Resultado |
|---|---|---|
| Iniciar la BD de pruebas | `scripts/pruebas/ambiente.sh up` | PostgreSQL 17 en Docker (imagen fijada por digest), `127.0.0.1:55432`, datos en `tmpfs` (se pierden al apagar) |
| Obtener la URL | `scripts/pruebas/ambiente.sh url` | `TEST_DATABASE_URL` con credenciales de prueba (no secretas, solo válidas en ese contenedor) |
| Cargar datos ficticios | `scripts/pruebas/ambiente.sh seed` | 4 distritos TSE, 5 lugares OSM y un año de OIJ, todos inventados |
| Limpiar | `scripts/pruebas/ambiente.sh limpiar` | `TRUNCATE` de todas las tablas; el esquema se conserva |
| Apagar y borrar todo | `scripts/pruebas/ambiente.sh down` | elimina el contenedor y sus datos |
| Todo junto (unitarias + integración + autorización) | `scripts/pruebas/ejecutar.sh` | inicia, ejecuta, apaga; salida 0 / 1 / 2 (2 = sin Docker, **incompleto**) |

**Repetible:** se verificó el ciclo `up → seed → limpiar → seed → down` y `ejecutar.sh` desde cero varias veces; cada ejecución parte de una BD vacía.

**Cuentas con distintos permisos.** El sistema no tiene cuentas ([Q-01](../../01-planificacion/kb/preguntas-abiertas.md#q-01), [Q-02](../../01-planificacion/kb/preguntas-abiertas.md#q-02)): los dos roles son el visitante (sin cabecera) y el operador (`X-Admin-Key`). Las pruebas usan una clave **ficticia** de 35 caracteres (`apoyo.cjs`), distinta de cualquier clave real. No existen propiedad de recursos ni sesiones.

**Salvaguardas.** `apoyo.cjs` se niega a conectarse a una BD que no sea `127.0.0.1` o `localhost`; sin `TEST_DATABASE_URL` la prueba **falla** con un mensaje claro (incompleta, no aprobada). Los datos del padrón son siempre ZIP armados en la prueba con cédulas y nombres inventados (`backend/scripts/pruebas/zip.cjs`).

Archivos: `scripts/pruebas/ambiente.sh`, `scripts/pruebas/ejecutar.sh`, `backend/scripts/pruebas/apoyo.cjs`, `sembrar.cjs`, `zip.cjs`.
