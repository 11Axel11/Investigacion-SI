# 4.4 E2E con Playwright de los tres flujos críticos

**Estado (2026-11-11):** 9 pruebas, 9 en verde en local (Chromium, 11,5 s). Reproducir: `scripts/pruebas/e2e.sh` (necesita Docker; instala Chromium con `cd e2e && npx playwright install chromium`). Informe HTML en `e2e/informe/`.

Se maneja la **interfaz real** (Next.js) contra el backend compilado y la BD de pruebas; Overpass y el OIJ se simulan sin tocar el código de la aplicación (`e2e/soporte/externos.cjs` y `precarga.cjs`, que sustituye `fetch` solo para las dos URLs del OIJ). Archivo: `e2e/pruebas/flujos.spec.js`; configuración: `e2e/playwright.config.js`.

| Flujo | Caso | Criterio |
|---|---|---|
| F-01 | el operador importa un ZIP ficticio, ve «5 electores · 3 distritos», la provincia y el distrito, y **ninguna pantalla** contiene cédula, nombre ni vencimiento | F01-AC1, F01-AC2 |
| F-01 | **rechazo:** sin modo operador el botón está deshabilitado | F01-AC7 |
| F-01 | **rechazo:** clave incorrecta → 401, mensaje comprensible, la clave se descarta y no se importa nada | F01-AC7 |
| F-01 | **rechazo:** un archivo que no es ZIP → mensaje, sin cambios | F01-AC3 |
| F-02 | el operador sincroniza el año (3 registros) y la segunda vez dice «Se utilizó la copia reciente» | F02-AC1, F02-AC2 |
| F-02 | **rechazo:** sin modo operador no se puede sincronizar | F02-AC5 |
| F-02 | **rechazo:** clave incorrecta → 401, mensaje, sin datos | F02-AC5 |
| F-03 | el operador sincroniza (2 lugares), la segunda vez «· caché»; tras recargar (un visitante, sin clave) ve los lugares | F03-AC1, F03-AC2, F03-AC6 |
| F-03 | **rechazo:** clave incorrecta → 401 y no se guarda ningún lugar | F03-AC7 |

Cada prueba empieza con la BD vacía. Una nota técnica: Next agrega su propio `role="alert"` (anunciador de rutas), por eso los casos de error se localizan por `[data-slot="alert"]`; fue la única corrección que hizo falta (3 pruebas fallaron al principio por selector ambiguo, sin cambiar ninguna expectativa).

**Dependencia nueva:** `@playwright/test` 1.61.0 en `e2e/package.json` (solo desarrollo, paquete aparte para no tocar el frontend). Justificación: el ítem 4.4 exige Playwright. No se agregó nada a `backend/` ni a `frontend/`.
